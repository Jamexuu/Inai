## Summary
This audit inspects the current Inai mobile & web codebase against the 40 mandatory rules of `antislop.md` and the additive skills (`antislop-ui`, `antislop-layoutmobile`, `antislop-human`, `antislop-copywriting`, `antislop-code`).

- **MEDIUM (Purpose-Gate):** Allowed techniques that lack written purpose, dose cap violations, or inconsistent hierarchies.

## Findings List

### HIGH Priority (Hard Gate)

1. **[R-24 / R-26 / C-2] Web Navigation Missing Routes in `app-tabs.web.tsx`**
   - **File:** `src/components/app-tabs.web.tsx#L18-L26`
   - **Rule:** R-24 (Navigation destinations must exist) & R-26 (Functional Completeness)
   - **Reason:** Web tab bar only implements `Today` and `Medicines`, completely omitting `Meals` (`/meals`), `Blood Pressure` (`/bp`), and `History` (`/history`), stranding web users and creating broken navigation paths.

2. **[R-03 / R-39] Touch Target Undersized (< 44px) on Filter Chips & Quick Action Buttons**
   - **Files:**
     - `src/app/history.tsx#L186-L213` (Filter pills are ~34px tall)
     - `src/app/index.tsx#L268-L275` ("Add" button in SectionHeader is `min-h-[40px]`)
     - `src/app/meals.tsx#L141-L148` ("Add Meal" button in SectionHeader is `min-h-[40px]`)
     - `src/components/ui/meal-card.tsx#L58-L64` (Meal edit button is `p-1.5` ~30x30px)
     - `src/app/bp.tsx#L231-L239` (BP edit button is ~26px tall)
     - `src/components/ui/medicine-card.tsx#L91-L96` ("Change" button is `min-h-[40px]`)
   - **Rule:** R-03 (Minimum tap target 44x44px for thumb comfort) & R-39 (Interaction Affordances)
   - **Reason:** Interactive controls are packed under 44px, causing miss-taps for an older adult thumb on physical devices.

3. **[R-25 / R-39] Color Contrast & Typography Scale Failures for Aging Eyes**
   - **Files:**
     - `src/components/app-tabs.tsx#L39` (Tab label font size is 11px)
     - `src/app/history.tsx#L252` (Timestamps and notes use `text-xs text-umber` at 12px)
     - `src/app/explore.tsx#L180-L182` (`text-muted-gray` on linen canvas has < 3.8:1 contrast)
     - `src/components/ui/skeleton.tsx#L47` (Hardcoded `#E5E0D8` on light canvas has low edge contrast)
   - **Rule:** R-25 (Color Contrast WCAG AA minimum 4.5:1) & R-39 (Accessible Semantics)
   - **Reason:** Micro-text (11px–12px) and muted gray shades fail WCAG AA readability for a 55-year-old mother.

4. **[R-27 / C-4] Missing Screen Error States & Resilience**
   - **Files:**
     - `src/app/index.tsx#L47-L49`
     - `src/app/meals.tsx#L46-L48`
     - `src/app/history.tsx#L145-L147`
     - `src/app/bp.tsx#L50-L52`
     - `src/app/explore.tsx#L45-L47`
   - **Rule:** R-27 (UI States: Empty, Loading, and Error must all be designed) & C-4 (Resilience)
   - **Reason:** Data fetching failures only log to `console.error` and leave an empty or blank screen without an actionable retry UI.

5. **[R-34] Broken Dark Mode Configuration at Root Shell**
   - **Files:**
     - `src/app/_layout.tsx#L69` (`StatusBar` and background hardcoded to `#FAF7F2`)
     - `src/app/_layout.tsx#L68` (`ThemeProvider` always uses `DefaultTheme`, ignoring dark mode)
     - `src/components/app-tabs.tsx#L9` (`const colors = Colors.light` hardcoded regardless of system theme)
   - **Rule:** R-34 (Every Theme You Ship Must Work)
   - **Reason:** Theme tokens for dark mode exist in `theme.ts` and `tailwind.config.js`, but the root app shell hardcodes light mode tokens, creating jarring mismatched theme flashes or unreadable dark surfaces.

### MEDIUM Priority (Purpose-Gate)

6. **[R-11] Inconsistent Border Radius Hierarchy Across Components**
   - **Files:**
     - `src/components/ui/status-badge.tsx#L40` (`rounded-full`)
     - `src/app/index.tsx#L166` (`rounded-md` on routine count badge)
     - `src/components/ui/medicine-card.tsx#L25` (`rounded-2xl` card with `rounded-xl` buttons)
     - `src/app/history.tsx#L199` (`rounded-full` on filter buttons)
   - **Rule:** R-11 (Radius variation must be deliberate and hierarchical)
   - **Reason:** Indiscriminate use of `rounded-full` capsules alongside `rounded-md` and `rounded-2xl` degrades UI cohesion. Status badges and pills should follow a consistent design system scale (`rounded-xl` for chips, `rounded-2xl` for cards).

7. **[R-12] Unmotivated Shadows Mixed with Solid Borders**
   - **Files:**
     - `src/components/ui/medicine-card.tsx#L25` (`shadow-sm` on top of `border-[1.5px] border-subtle-border`)
     - `src/components/app-tabs.web.tsx#L51` (`shadow-sm`)
     - `src/components/permission-prompt-modal.tsx#L58` (`shadow-xl`)
   - **Rule:** R-12 (Shadow must support visual elevation, not be sprayed as a default)
   - **Reason:** Mixing floating drop shadows with thick tactile borders creates an artificial, muddy surface plane. Flat tactile surfaces with solid borders (`border-stone-200`) match Mom's calm linen aesthetic much better.

8. **[R-14 / R-05] Uniform Feature Cards Without Visual Urgency**
   - **Files:**
     - `src/app/index.tsx#L287-L295`
     - `src/components/ui/medicine-card.tsx#L25-L98`
   - **Rule:** R-14 (Card variation reflecting content hierarchy) & R-05 (Layout driven by content needs)
   - **Reason:** All cards in the today list have identical visual weight. Doses that are due right now should have distinct focus and clear separation from already completed or later evening doses.

      - `src/components/ui/meal-card.tsx#L27-L33`

    - **Reason:** Over 30 instances of raw hex codes (`#3D5A50`, `#C46849`, `#6B645D`) are embedded directly in component markup instead of referencing the design token constants in `theme.ts` or tailwind classes.
